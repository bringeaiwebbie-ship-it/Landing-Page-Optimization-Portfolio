# Bringeai Webbie — Landing Page Optimization Portfolio

A responsive, strategy-led portfolio website for Bringeai Webbie, focused on landing page conversion rate optimization.

## Project structure

- `index.html` — page content and structure
- `css/style.css` — responsive visual design
- `js/main.js` — mobile navigation, current year and enquiry form

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Deploy on Vercel

Import this GitHub repository into Vercel. This is a static HTML/CSS/JavaScript site:
- Framework preset: Other
- Build command: leave empty
- Output directory: leave empty / default
- Root directory: `./`

## Before launch

1. Replace `hello@bringeaiwebbie.com` in `js/main.js` with your real business email address. The contact form currently opens the visitor's default email application; it does not submit to a server.
2. Review all copy and contact details.
3. The Northline Roofing, Meridian Advisory and Stillpoint Wellness examples are explicitly labelled concept projects. They are illustrative work, not commissioned clients or evidence of measured results. Keep that disclosure visible unless the work is replaced with genuine client case studies.
4. Test the page on mobile and desktop after deployment.

## Brand direction

Premium, editorial and understated: charcoal, warm ivory and champagne-gold accents, with a clear focus on business outcomes rather than visual redesign alone.
